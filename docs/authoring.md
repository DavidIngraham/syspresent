# Author canvas presentations

A portable project contains SysML/KerML sources, any required custom libraries, optional presentation-owned view files, `story.md` and bundled assets. The browser discovers ordinary files and native model roots. The optional `project.json` records title, navigation and publication intent; it does not duplicate generated model indexes or tool hashes.

Use Project to import files, folders or a ZIP. Explore native views, capture supported viewpoints, and edit scene prose and supporting content. System model sources remain read-only; presentation views and Markdown are editable. Project > Export project ZIP retains ordinary files for reimport. Markdown can also be imported or exported independently.

[Canvas story content](canvas-story-content.md) defines scene blocks, chapters, figures, semantic prose links and evidence provenance. [Configuration](configuration.md) covers entry points and display preferences; [integration](integration.md) explains native view ownership, capture limits and model identity. The examples in `examples/canvas-prototype`, `examples/canvas-views` and `examples/canvas-blue-dog` are executable authoring references.

Native SysML views own reusable model selection. Prose, scene order, emphasis and transition choreography are presentation content. Reference model decisions, assumptions and evidence explicitly; a displayed claim or modeled verification case is not executed evidence or engineering approval.
