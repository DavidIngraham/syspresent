# Canvas implementation status

Syspresent has one application: the graph canvas at the GitHub Pages project root. Its multi-demo landing page, local project import, native Go/WASM worker, focused exploration, guided stories and portable editor share the same build and publication path.

See [canvas evidence](canvas-prototype.md) and [requirements evidence](requirements-evidence.md) for exercised behaviors and limits. Native SysML remains authoritative; scope, hidden context and unsupported operations are disclosed. Making this app the default does not complete all intended product requirements or the pending [reader study](reader-study.md).
