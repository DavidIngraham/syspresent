# UX research basis

These sources inform design hypotheses. None establishes that Syspresent's particular SysML review experience is effective; product comprehension must be tested with representative readers.

| Source | Evidence and implication |
| --- | --- |
| [van Ham and Perer, 2009](https://perer.org/papers/adamPerer-DOIGraphs-InfoVis2009.pdf) | Search, show context, expand on demand is a demonstrated design approach for large graphs, not a universal controlled-comparison result. Use local exploration and explicit context. |
| [Ghoniem, Fekete and Castagliola, 2004](https://courses.ischool.berkeley.edu/i247/f05/readings/Ghoniem-GraphReadability_InfoVis04.pdf) | Node-link versus matrix experiments show task dependence: paths favor node-link, many dense-graph tasks favor matrices. Do not turn their experimental node threshold into a product rule. |
| [Ware et al., 2002](https://vislab-ccom.unh.edu/pdfs/GraphAesthetics.pdf) | Path comprehension depends on graph geometry. Evaluate crossings, continuity and readable labels, not visual spectacle. |
| [McKenna et al., 2017](https://www.microsoft.com/en-us/research/wp-content/uploads/2017/08/VisualNarrativeFlow-EuroVis2017.pdf) | Exploratory studies and a 240-participant study examine narrative flow and engagement. No universal scrolling advantage is established; observed precision-scroll problems motivate stable scene intervals. |
| [Heer and Robertson, 2007](https://pubmed.ncbi.nlm.nih.gov/17968070/) | Controlled experiments support well-designed transitions for certain statistical graphics tasks; this is not evidence for arbitrary model fly-throughs. |
| [Archambault, Purchase and Pinaud, 2011](https://pubmed.ncbi.nlm.nih.gov/20498503/) | Small multiples were faster in tested dynamic-graph tasks; animation reduced errors in some change-identification tasks. Fixed positions are not always better. Support simultaneous comparison. |
| [Stokes et al., 2022](https://arxiv.org/abs/2208.01780) | Text/chart experiments demonstrate that narrative affects takeaways. Coordinate prose and visual emphasis; do not equate preference with understanding. |

## Product evaluation

Use representative technically minded readers unfamiliar with Blue Dog. Tasks: trace a requirement, distinguish satisfaction from verification, identify a shared cause, interpret a behavioral branch, explore across a library boundary and return to the exact story context. Record accuracy, completion time, navigation errors, confidence, preference and qualitative observations. Include mobile and reduced-motion checks.

A small formative study diagnoses usability problems; it does not establish statistical superiority. Participant count, performance budgets and acceptance thresholds remain explicit open decisions. No fixed 15–25-node limit is justified by the literature.
