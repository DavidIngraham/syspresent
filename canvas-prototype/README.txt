Syspresent standalone canvas prototype
Serve this directory using any static web server, for example:
  python3 -m http.server 8783
Open http://localhost:8783/ in your browser. The Go/WASM engine runs in a Web Worker; no application backend is used.
Project > Export project ZIP exports ordinary model/view/Markdown files.
This artifact is a prototype, not a completed full-product release.
